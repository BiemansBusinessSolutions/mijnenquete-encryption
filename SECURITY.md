# Reporting security issues

Please report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/BiemansBusinessSolutions/mijnenquete-encryption/security/advisories/new)
or email [veiligheid@mijnenquete.nl](mailto:veiligheid@mijnenquete.nl).
The same address accepts encryption and security questions.

If GitHub asks for a CWE and you do not know which classification fits, email us
instead. You do not need to guess a category to make a useful report.

Include the affected release/source revision, expected and actual behaviour,
browser version and minimal steps using synthetic data. Do not send live
passwords, private keys, backup codes, credentials or respondents' answers.

Please avoid public issues for unpatched vulnerabilities. Test only accounts
and surveys you own or have explicit permission to test. Do not access other
people's data, disrupt the service or run high-volume scans. Contact us before
testing anything that could affect other users.

The main branch tracks published snapshots; check the relevant source tag and
manifest when reporting older versions. Reports are reviewed by the maintainer;
this policy promises neither a bounty nor a response-time guarantee.
